# Welcome to N Viewer

N Viewer is designed for one thing: **quiet, comfortable reading**.

## Markdown support

- Headings, lists, quotes and links
- Tables that remain usable on narrow windows
- Syntax-highlighted code blocks
- Local raster images stored beside the Markdown document
- Clean A4 PDF export

> Remote images are blocked to protect your privacy.

## Code sample

```javascript
function openDocument(filePath) {
  return viewer.open(filePath);
}
```

## Table sample

| Feature | Behavior |
|---|---|
| PDF saving | Exact byte-for-byte file copy |
| Markdown saving | Clean PDF export |
| Dark mode | Semantic Markdown theme and optional PDF night filter |
| Internet | Not required for reading |

Use **Ctrl+O** to open another document and **F11** for full-screen reading.
